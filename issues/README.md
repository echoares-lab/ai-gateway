# Issues directory

**Source of truth for active work:** GitHub issues plus
[`docs/ROADMAP.md`](../docs/ROADMAP.md) (approved) and
[`docs/FEATURE_CANDIDATES.md`](../docs/FEATURE_CANDIDATES.md) (unapproved inventory).

`issues/archive/` holds historical markdown issue drafts and post-audit notes.
Do **not** claim or implement from archived files. Prefer opening or updating
GitHub issues when promoting candidates.

Process: [`docs/process/REPO_IMPROVEMENT_WORKFLOW.md`](../docs/process/REPO_IMPROVEMENT_WORKFLOW.md).
